# Improved version of the classic video game Colossal Cave Adventure

This is a brand new project in an empty folder. The goal is to create a game that is similar to the classic Collosal Cave Adventure but slightly refined. 

Please read the wikipedia article about the original game: https://en.wikipedia.org/wiki/Colossal_Cave_Adventure

Refinements to consider:
- Game plays in a web browser
- Game uses AI generated graphics. One graphic for each location, one graphic for each item, one for each character/monster, etc...
- Consider options to replace the classic games 1 or 2 word text input method of gameplay.
- There should be buttons and keyboard shortcuts for common functions, such as "show map" or "inventory"
- The game should allow the user to save and load games
- The game should be configured with future expansion in mind. We may want to add a new "adventure" that has it's own map, monsters, items, etc...
- Research and suggest additional refinements or gameplay mechanics keeping in the spirit of the original.
